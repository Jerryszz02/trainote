Trainote 帮助与反馈

健康分析版本草稿 · 需要 iOS 17 或更高版本

数据保存在哪里？

所有训练和饮食记录都保存在当前设备。Trainote 没有账号和云同步功能。

如何删除数据？

单条记录可以在对应列表中编辑或删除。若要删除全部本地数据，可以卸载应用。

更换手机后能自动恢复吗？

Trainote 不提供自己的同步服务。你可以在设置中导出 JSON 备份，在新设备中选择“恢复本地备份”。恢复前会显示记录数量；已有相同 ID 的记录会跳过，不会删除当前数据。也可以继续使用 iPhone 系统备份与迁移功能。

备份文件安全吗？

备份可能包含个人训练、饮食和手动健康记录。请只保存到你信任的位置并避免公开分享。Trainote 不会自动上传备份。

资料库和设置在哪里？

底部为今日、训练、饮食、趋势、恢复。完整资料库从今日的书本入口打开；今日“管理模板”直达模板区，训练页可进入动作/模板，饮食页可进入常用食物/固定餐。今日齿轮继续提供手动目标和备份。

可以不连接健康或 AI 吗？

可以。首启选择“暂时仅本地使用”即可继续记录。健康连接和 AI 同意分别选择。当前 AI 尚未开放，仍可使用本地记录，不会预先代你同意。

如何断开和撤回？

设置中的“断开并删除健康导入数据”清除缓存、锚点及依赖报告，保留手动记录。关闭 AI 停止后续请求并撤回服务器同意；失败需重试。单独删除报告不会删除训练或饮食。

v2 备份包含什么？

包含手动健康资料、目标历史和原有记录，支持导入 v1 / v2。健康缓存、授权、设备凭据和派生报告不导出，恢复后重新选择连接。旧 App 不保证能读 v2。

反馈问题

请在 GitHub Issues 提交问题。为了保护隐私，请不要附上真实训练、饮食、健康信息或其他敏感内容。
