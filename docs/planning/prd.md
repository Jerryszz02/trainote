# Trainote iOS v1 产品需求

## 文档目的

定义第一版 Trainote 必须提供的用户行为，使实现者无需重新决定产品范围。

## 适用范围

适用于 iPhone、iOS 17+ 的中文离线 App。目标用户是希望记录训练表现和每日营养摄入的个人用户。

## 产品目标

- 力量训练按动作逐组记录重量、次数和完成状态。
- 有氧训练记录时长、距离和可选消耗热量。
- 用户可创建有序 routine，并用其开始一份独立训练日志。
- 饮食记录同时包含卡路里、碳水、蛋白质和脂肪。
- 用户可保存常用食物、固定餐和每日营养目标。
- 全部数据本机保存；关闭和重启 App 后仍可继续进行中的训练。

## 页面和主流程

### 今日

- 显示当天卡路里和三大营养素的已摄入、目标和剩余值。
- 显示当天训练摘要。
- 提供“开始训练”和“记录饮食”快捷入口。
- 没有营养目标时显示设置入口，不阻止其他功能。

### 训练

- 历史列表按日期倒序显示训练状态和摘要。
- 用户可开始空白训练，或从 routine 复制动作与计划参数。
- 动作目录提供推荐默认方式；用户可选择重量×次数、次数、时长、有氧。切换时保留数值并重置组完成状态。
- 力量动作可新增、删除和勾选组；每组保存非负重量和正整数次数。
- 有氧动作要求正数时长，距离和热量可留空。
- 至少一个完成组或一条有效有氧记录后才能完成训练。
- 退出进行中的训练页面不会删除数据；明确放弃时二次确认。
- routine 修改或删除后，不改写已经开始或完成的训练。

### 饮食

- 选择日期后，按早餐、午餐、晚餐、加餐分组显示日志。
- 可直接输入名称、份量、卡路里、碳水、蛋白质和脂肪。
- 可从常用食物生成日志；日志保存营养快照。
- 可从固定餐一次生成多条食物日志，落入同一餐次和记录时间。
- 日志支持编辑和确认删除；当天汇总即时更新。

### 资料库

- 动作目录支持中文名、英文名、身体部位、器械、目标肌肉搜索与筛选。
- 动作详情显示双语名称、分类、肌群、中英文说明和数据来源。
- routine 支持创建、重命名、排序动作、设置默认参数、删除和开始训练。
- 常用食物和固定餐支持创建、编辑和删除。
- 设置页管理每日营养目标。

## 业务规则和边界状态

- 组数由力量组记录数量得出，不维护第二份总组数字段。
- 自重动作允许重量为 0；负数、NaN 和无穷值不允许保存。
- 热量与宏量营养素独立录入，不强制按 4/4/9 公式相等。
- 进度条最多绘制到 100%，但文字必须显示真实超标数值。
- 动作目录加载失败时显示可重试错误页，不能以空目录冒充成功。
- 搜索无结果、没有训练、没有饮食记录、没有 routine 时均提供明确空状态和下一步操作。

## 非功能需求

- 运行时零网络请求、零账号、零分析与遥测。
- 使用系统语义色、深浅色、Dynamic Type 和 VoiceOver 标签；不能只用颜色表达是否超标或完成。
- 常见录入操作应可单手完成，数值字段使用合适的数字键盘。
- 动作目录 1,324 条全量本地搜索不应造成可感知卡顿。

## 1.1 日常使用升级

- 上次表现、参数沿用、休息计时、历史编辑、再次训练与保存训练模板。
- 最近食物、复制一餐、每 100g/每份换算与固定餐分量调整。
- 周报与重量/容量 PR；首次是基线，平纪录不算突破，漏记日期不按零摄入。
- 带版本的 JSON 本地备份、完整校验与原子恢复，不自动覆盖同 ID 记录。
- 详细规则见 [升级计划](daily-use-upgrade.md)。

## 非目标

不包含图片/GIF、iCloud、登录、HealthKit、Apple Watch、iPad、条码扫描、在线食物库、身体体重、训练推荐、自动目标计算、superset 或专业医疗/训练建议。

## 验收标准

- 用户可完整走通力量、有氧、routine、常用食物、固定餐和营养目标流程。
- App 重启后历史和进行中训练保持一致。
- 动作目录包含固定上游版本的全部 1,324 个动作，且不包含媒体资源。
- 所有必需自动化测试通过，人工验收覆盖深浅色、辅助功能、键盘和空状态。
