# App Review 说明草稿

Trainote 是一款完全离线的训练与饮食记录工具，不需要账号、网络连接或审核测试账号。

建议审核路径：

1. 在“训练”页点击“开始训练”，选择“空白训练”。
2. 打开进行中的训练，添加任意力量或有氧动作。
3. 在“饮食”页点击右上角加号，选择“直接记录”。
4. 在“资料库”页查看内置动作、routine、常用食物和固定餐。
5. 在“今日”页右上角进入设置，可设置每日营养目标并查看数据与许可证说明。

隐私说明：训练、饮食、routine、食物模板和营养目标只保存在设备本地。App 不包含账号、后端、广告、分析、追踪、遥测或第三方在线 SDK。

健康说明：App 仅供手动记录，不生成医疗、诊断、治疗或个性化专业训练建议。

内容权利：内置动作目录使用 MIT 许可的数据结构、元数据和说明文字，并在 App 包内及“关于”页面保留来源与许可信息；没有分发原数据集中的图片或 GIF。
