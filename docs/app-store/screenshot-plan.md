# App Store 截图计划

仅支持 iPhone。使用 6.9 英寸 iPhone 模拟器竖屏截图，准备 5 张主截图；截图不得包含真实个人健康或饮食数据。

| 顺序 | 页面 | 建议画面 | 标题文案 |
| --- | --- | --- | --- |
| 1 | 今日 | 已设置营养目标，展示进度和当日训练 | `训练和饮食，一页看清` |
| 2 | 进行中训练 | 两个力量动作，包含已完成和未完成组 | `每一组都记录清楚` |
| 3 | 动作选择 | 中文搜索与筛选后的动作目录 | `1,324 个中英双语动作` |
| 4 | 饮食 | 早餐、午餐和加餐记录及营养汇总 | `每一餐，快速记下来` |
| 5 | 每周回顾 | 本周训练、重量/容量 PR 与饮食记录完整度 | `看见每一周的积累` |

健康版本追加候选画面（最终验收后再制作，不替换已核实的历史截图）：趋势页的样例体重与目标历史、恢复页的 3D/肌群列表及未知状态、需要明确确认的训练建议、本地基础报告。样例数据须人工或测试输入，不能伪装成用户的实际健康效果；报告日统计窗口已修复并完成定向 UI 验证；现有验收截图只作工程证据，最终宣传截图仍待完整验收和人工核对。

正式截图前检查：

- 时间、电量和运营商状态栏保持一致。
- 使用示例数据，不出现姓名、身体指标或其他真实隐私信息。
- 浅色模式为主；如增加深色模式截图，保持同一组数据。
- 截图只展示 App 实际界面，不加入无法在 App 中实现的功能描述。
- 截图标题后期排版时不要遮挡关键控件。
