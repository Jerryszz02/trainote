## 描述

Trainote 是一款中文优先、完全离线的训练与饮食记录 App。

按动作选择重量×次数、纯次数、时长或有氧记录，查看上次表现并使用组间休息计时。建立自己的训练模板，从最近食物、常用食物或固定餐快速记下一餐，按实际分量计算营养，并在每周回顾中看到积累与个人纪录。

主要功能：

- 记录负重、自重、静态保持和有氧训练
- 记录有氧训练的时长、距离和热量
- 创建、复用训练模板，编辑历史或再次训练
- 内置 1,324 个中英双语动作
- 记录早餐、午餐、晚餐和加餐
- 保存常用食物与固定餐，复制一餐，按份或每 100 克调整用量
- 查看每周回顾、重量 PR 与单次训练容量 PR
- 导出和恢复本地备份
- 设置每日热量和三大营养素目标
- 无账号、无广告、无分析与追踪
- 所有数据仅保存在本机

Trainote 是记录工具，不提供医疗诊断、治疗建议或个性化专业训练建议。
